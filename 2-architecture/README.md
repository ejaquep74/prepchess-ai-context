# 2-Architecture

## Purpose
Contains the technical specifications, algorithmic contracts, and system constraints governing both frontend and backend implementations across the PrepChess ecosystem.

## Key Files
* **[FRONTEND_HOLLOW.md](file:///home/ejaque/projects/prepchess/prepchess-ai-context/2-architecture/FRONTEND_HOLLOW.md):** Security constraints and tech stack for the presentation-only React client (`prepchess-ui`). Establishes the rule that UI does no chess math.
* **[BACKEND_ENGINE.md](file:///home/ejaque/projects/prepchess/prepchess-ai-context/2-architecture/BACKEND_ENGINE.md):** Algorithmic and mathematical specifications for `opening-explorer` (Java 21), including Expectiminimax, utility functions $U(n)$, and Maia-3 refutation search.
* **[SYSTEM_DESIGN.md](file:///home/ejaque/projects/prepchess/prepchess-ai-context/2-architecture/SYSTEM_DESIGN.md):** End-to-end topology, database schemas, Caffeine cache layers, and the Metadata Injection AI commentary pipeline.
